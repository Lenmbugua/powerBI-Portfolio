**📊 Data Professional Survey Dashboard**



**📝 Project Overview**



**This project analyzes survey responses from data professionals around the world. The goal is to uncover insights about salaries, job roles, favorite programming languages, geographical distribution, and overall satisfaction levels in the data industry.**



**The project includes:**

**Dataset (Professional Survey Data.xlsx)**



**An interactive Power BI dashboard (Data Professional Survey Dashboard.pdf – screenshot of the main report view)**



**📂 Dataset Summary**



**Source: Professional Survey Data (Excel file)**

**Contents: Responses from 630 survey participants**



**Field	Description**

**Age	Age of the respondent**

**Job Title	Data-related role (Data Scientist, Analyst, etc.)**

**Country	Respondent's country**

**Favorite Programming Language	Most-used language in their work**

**Salary	Reported annual salary**

**Happiness with Salary	Self-reported satisfaction (scale-based)**

**Happiness with Work/Life Balance	Self-reported satisfaction with work-life balance**

**Difficulty Breaking Into Data	Respondent’s view on how hard it is to enter the field**



**📈 Dashboard Highlights**



**The dashboard summarizes key insights:**



**Total Respondents: 630**



**Average Age of Respondents: ~29.87 years**



**Average Salary by Job Title – Compare compensation across data roles**



**Favorite Programming Languages – Popular tools used in the data field**



**Geographical Distribution – Top countries represented in the survey**



**Happiness Metrics – Work-life balance and salary satisfaction levels**



**Difficulty Breaking into Data – Community perception of entry difficulty**



**🛠️ Tools \& Technologies**
